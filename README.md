# Unduhan Bro Sampah

Unduh aplikasi Android Bro Sampah dari halaman [rilis](https://github.com/Bro-Sampah-Indonesia/releases/releases).

APK mendukung Android 7.0 atau lebih baru. Informasi layanan dan demo yang dapat dicoba tanpa instalasi tersedia di [brosampah.com](https://brosampah.com).

Layanan penjemputan saat ini tersedia di Universitas Sebelas Maret.
